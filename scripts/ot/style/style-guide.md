# Gbible 旧約ヘブル語 日本語化スタイルガイド

このガイドは、辞書（3ペイン）と2ペインの短い訳を AI で作るときに、毎回プロンプトに入れる共通ルールです。人が確認するときの基準にもなります。

## 1. 読者
- 日本語で聖書を読み、説教・学び会のためにヘブル語原文を確かめたい牧師・信徒。
- ヘブル語は初学者〜中級者。文法用語には短い補足を添える。

## 2. 表記の基準
- 固有名詞・祭儀用語・度量衡は **新改訳2017** の表記に合わせる。
  - 例: エポデ（×エフォド）、ギルアデ（×ギレアデ・ギレアド）、ミツパ、ヤハウェではなく「主」（神名 יהוה は「主」と訳し、辞書では「神の固有の御名（YHWH）」と説明する）。
  - 付属の固有名詞対照表（names-ja.json）にある語は、必ずその表記を使う。
  - 対照表にない固有名詞は新改訳2017の表記を使い、確信が持てない場合は `nameUncertain: true` を付ける。
- 神を指す代名詞・動詞に特別な敬語は付けない（「神は言われた」程度の新改訳の文体は可）。
- 数字は漢数字（七十、九十）。単位は新改訳2017（キュビト、エパ、シェケル など）。
- ひらがな・漢字の使い分けは新改訳2017に近づける（例: 僕→しもべ、たたく、ことば は文脈で自然な方）。

## 3. 著作権
- 新改訳2017を含む日本語訳聖書の本文を、辞書や訳の中で引用しない。聖書箇所を示すときは「詩23:1」のように箇所だけを書くか、ヘブル語からの自前の短い訳を添える。
- 英語辞典（TBESH・BDB・Strong's）は資料として使ってよいが、英文をそのまま訳し写すのではなく、日本語の読者向けに再構成する。

## 4. 聖書箇所の書き方
- 書名は次の略号＋章:節。例: 創1:1、出3:14、申6:4、詩23:1、箴1:7、イザ53:5、エレ31:31、ダニ7:13、ヨナ2:9、ミカ5:2。
- 略号: 創 出 レ 民 申 ヨシュ 士 ルツ 1サム 2サム 1列 2列 1歴 2歴 エズ ネヘ エス ヨブ 詩 箴 伝 雅 イザ エレ 哀 エゼ ダニ ホセ ヨエ アモ オバ ヨナ ミカ ナホ ハバ ゼパ ハガ ゼカ マラ。
- 新約聖書の略号: マタ マル ルカ ヨハ 使 ロマ 1コリ 2コリ ガラ エペ ピリ コロ 1テサ 2テサ 1テモ 2テモ テト ピレ ヘブ ヤコ 1ペテ 2ペテ 1ヨハ 2ヨハ 3ヨハ ユダ 黙。「マタイ1章」のような書き方はしない。
- ギリシア語は原語のまま書き（例: μακάριος、διάψαλμα）、カタカナ表記にしない。
- 辞典・資料の名前は「BDB」「Strong's」「TBESH」「LXX（七十人訳）」と書いてよい。それ以外の英語は日本語にする。
- 文体は常体（〜である・〜を表す）にそろえる。
- 節番号は新改訳2017と同じ番号（詩篇の表題は数えない）。
- 箇所は、実在し、その語が実際に使われている箇所だけを書く。自信がない箇所は書かない。

## 5. 辞書（3ペイン）
- `glossJa`: 見出し語の代表的な訳。辞書形・8文字以内（例: 創造する、初め、羊飼い）。
- `definitionJa`: 中心的な意味を15文字以内で。
- `detailJa`: 300〜450字。①②③…で用法を整理し、それぞれに代表的な箇所を付ける。語源・語根、重要な神学的用法、新約聖書・七十人訳（LXX）とのつながりがあれば簡潔に触れる。断定しすぎず、学説が分かれる点は「〜とも解される」とする。

## 6. 2ペインの短い訳（文脈訳）
- その節の文脈で、その語が表す意味を日本語で。**10文字以内**。
- 接頭辞（ו・ה・ב・ל・מ・כ）と人称接尾辞を含めて、その語全体を訳す。例:
  - וַיֹּאמֶר → 「そして言った」
  - בְּרֵאשִׁית → 「初めに」
  - רֹעִי → 「私の羊飼い」
  - לְדָוִד → 「ダビデの」（詩篇表題）／「ダビデに」（文脈による）
- 動詞は、時制・態・人称が分かる最小限の形に（言った／言う／言え、与えられた）。
- 目的語標識 אֵת は「（目的語）」、冠詞のみの語はない。訳しにくい小辞は機能を括弧で示す（例: 「（強調）」「見よ」）。
- 句読点・記号・英語・説明文は入れない。
- 同じ語でも文脈で訳を変えてよい（例: נֶפֶשׁ → 魂／命／私自身）。ただし、辞書の意味から外れる意訳はしない。
